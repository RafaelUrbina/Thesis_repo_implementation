# Thesis Project: Decision Support System for Long-Distance Liquid Transportation

## Overview
This repository contains the implementation work for a thesis focused on **integrating heterogeneous data sources** in the context of **long-distance liquid transportation**, specifically water sources and sewage external risks, in the italian territory (specific region Toscana).  
The goal is to develop a **decision support system (DSS)** designed to assist **policy makers, industry stakeholders, and related entities** in making informed, data-driven decisions.

## Research Context
The project is grounded in the paradigms of **Industry 4.0** and **Industry 5.0**, concerning smart data integration, analysis and automation.  
It emphasizes:
- **Data heterogeneity management** across multiple sources (reports, historical datasets, etc.)
- **Interoperability** between industrial systems and policy tools
- **Human-ML collaboration** for enhanced decision transparency

## Proposed Solution
The proposed solution combines:
1. **Machine Learning (ML)** implementations for pattern recognition within transportation regions.  
2. **Natural Language Processing (NLP)**-based **Results**, enabling intuitive querying and insights generation — users can imput regions and receive structured, data-informed answers.

This hybrid architecture aims to make complex analytical results accessible to non-technical decision makers.
